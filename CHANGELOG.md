## 0.1.0 — 2026-10-16

First public release of layZ AgentKit for Blender 5.2 on Windows.

- Image Editor moodboard with image import, Windows clipboard paste, notes, groups, multi-selection, proportional scaling and Undo/Redo.
- Project-wide and object/collection reference boards with persistent bindings and managed image copies.
- JSON-safe Python API for agents using an existing MCP connection, with separate append-only agent feedback.
- Evaluated mesh inspection, six repeatable preview views and bounding-box fit checks.
- Versioned Unity-oriented FBX packages with image textures, preview, diagnostic reports and independent reimport validation.
- GPL-3.0-or-later license, installation/Unity import instructions and a ready-to-install Release ZIP.

Verified with Blender 5.2.2 LTS and sample imports in Unity 6000.3.23f1. First-release scope excludes animation, exact collision tests, procedural texture baking and automatic Unity material creation.
